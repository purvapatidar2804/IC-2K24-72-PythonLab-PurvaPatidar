## Lab 1
Lab 1 contains basic Python programs covering variables, input/output, arithmetic operations, strings, escape sequences, and a menu-driven calculator.
 
###  Programs Included

1. **Variable and Identifier Practice** - Demonstrates variables and their data types.
2. **Greeting Program** - Takes name, age, and city as input and displays a greeting using an f-string.
3. **Arithmetic Operations** - Performs basic arithmetic operations on two numbers.
4. **Celsius to Fahrenheit** - Converts temperature from Celsius to Fahrenheit.
5. **String Manipulation** - Performs different operations on a full name using string methods.
6. **Escape Sequence Practice** - Demonstrates the use of `\t` and `\n` using a simple receipt.
7. **Menu Driven Calculator** - Performs basic arithmetic operations through a menu-driven calculator.


## Lab 2
Lab 2 contains Python programs based on functions, loops, recursion, nested loops, user-defined modules, input validation, and the `random` module.

### Programs Included
1. **Armstrong Number** - Checks whether a number is an Armstrong number and prints Armstrong numbers within a given range.
2. **Prime Number** - Checks whether a number is prime and prints prime numbers up to a given limit.
3. **Perfect Number** - Checks whether a number is a perfect number and prints perfect numbers up to a given limit.
4. **Palindrome** - Checks whether a number and a string are palindromes.
5. **Fibonacci Series** - Generates the Fibonacci series using both loops and recursion.
6. **Pattern Printing** - Prints star, number, and centered pyramid patterns using nested loops.
7. **Menu-Driven Application** - Combines the programs from Lab 2 into a single menu-driven application.
8. **Number Guessing Game** - Generates a random number and allows the user to guess it within a maximum number of attempts.
